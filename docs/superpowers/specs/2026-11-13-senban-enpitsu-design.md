# 旋盤で鉛筆を削るゲーム 設計書（2026-11-13）

## 1. ねらい
鉛筆削りを忘れたので、なぜか旋盤で鉛筆を削る。大げさな道具で小さな用事を片づけるばかばかしさで笑わせ、遊びの中心は「点線の形にぴったり合わせて削る」腕前勝負にする。

- 導入はばかばかしさで笑わせる（ユーザーの決定）
- 遊びの芯は、点線の目標形にぴったり合わせて削ること（ユーザーの決定）
- ステージが進むと形が変わり、難しくなる（ユーザーの決定）
- ばかばかしい話は最後まで続き、毎回の形に理由がある（ユーザーの決定：案B）
- 成功の形：クリアタイムと形で点数・ランクがつき、それを共有できる（ユーザーの決定）

## 2. 目標 / やらないこと / 失敗とみなすこと
**目標**
- スマホのブラウザで、インストールなしにすぐ遊べる
- 削る手ごたえ（削りくず、音、振動）が気持ちいい
- 1面が短く、次の形と話を見たくなる
- 結果（削った形・ランク・タイム）を画像1枚にして SNS に投稿できる

**やらないこと（今回）**
- 全プレイヤーのオンラインランキング表（あとから足せる作りにはしておく）
- アカウント、課金、サーバー

**失敗とみなすこと（動いていてもダメ）**
- 削った形が点線と合っているのに点数が低い、など採点が不公平に感じる
- 話が長くて遊ぶまでが遠い（話は1面あたり1〜2行＋簡単な絵まで）
- スマホで重い、指で狙ったところを削れない

## 3. 作り方の候補と決定
- **A. 結果カード共有、サーバーなし（採用）**：Three.js で3D表示。共有は結果画像の投稿。早く作れて軽い。ランキング表はない。
- B. A＋全体ランキング表：競い合いが生まれるが、記録の保存とズル対策で作る量が大きく増える。今回は見送り。
- ゲームエンジン（Unity 等）での WebGL 書き出し：スマホで開くまでが重く、この規模には大がかりすぎるので除外。

ユーザーは A を選択。理由：まず遊びの面白さを早く確かめられ、ランキング表はあとで足せるため。

## 4. 遊びの流れ
1. タイトル → 導入（試験の朝、鉛筆削りを忘れた → なぜか家に旋盤がある）
2. 各面：話1〜2行 → 点線の目標形を表示 → 削る → 判定 → 結果
3. 前の面の失敗やごまかしが、次の面の形の理由になる。話はプレイヤーの腕前に関係なく毎回ひどくなっていく
4. 最終面のあとにエンディング

### 面の並び（案。話の中身は差し替えてよい）
| 面 | 形 | 話の例 | 難しさの要素 |
|---|---|---|---|
| 1 | 鉛筆の先（円すい） | 試験の朝、旋盤で削る | 練習。直線だけ |
| 2 | 段つき | 削りすぎて短い。段をつけて長く見せる | 段差 |
| 3 | こけし | 先生に見つかり「工作の課題です」 | 曲線 |
| 4 | チェスの駒 | 「美術部の作品です」 | 曲線＋深いくびれ |
| 5 | 試験官の顔 | 試験会場で試験官の顔を彫る | 細かい凹凸、折れやすい |

（面の数は5面を目安とする。作り手の判断）

- 最終面の顔は、横から見た輪郭が顔に見える回転体（ルビンの壺のような形）にする。旋盤を止めて彫る仕組みは作らない（ユーザーの決定）
- 鉛筆は面ごとに新しい1本になる。話の上ではつながっているが、前の面の削り具合は次の面に持ち越さない（ユーザーの決定）

## 5. 操作と仕組み
- 鉛筆は横向きに置かれて回転し続ける。刃は画面下側にあり、指のドラッグで軸方向（左右）と深さ（上下）を動かす
- 鉛筆の形は「軸方向の位置ごとの半径」の並び（輪郭）で持つ。刃の先が今の半径より内側に入った所だけ、半径を刃の位置まで小さくする。削った分は戻らない
- 目標の形も同じ半径の並びで持ち、点線として表示する
- 3D表示は Three.js の回転体（輪郭を軸まわりに回した形）。削るたびに形を作り直す
- 芯：中心に黒い芯があり、削り進むと見えてくる
- 折れ：細い所に刃を強く（速く深く）当てると折れて失敗。後半の面ほど効いてくる
- 演出：削りくずの粒、削る音、スマホの振動（対応端末のみ）

## 6. 採点とランク
- 一致率：軸方向の各位置で、削った半径と目標半径の差を測り、0〜100% にする。削りすぎ（目標より細い）は削り残しより重く減点する
- タイムボーナス：速いほど加点
- 合計点から S / A / B / C のランク
- 削り終わりはプレイヤーが「完成」ボタンで決める。制限時間はなし（タイムは点数にだけ効く）
- 折れたら、その面はやり直し
- 先へ進めなくなるのは折れたときだけ。ランクが C でも次の面へ進める。ランクは共有と、やり直しで上を狙うためのもの（ユーザーの決定）
- クリアした面は選び直して遊べる（作り手の判断）

（一致率の細かい式、減点の重み、ランクの境目、タイムボーナスの大きさは作り手が決めて、遊んでみて調整する）

## 7. 共有
- 各面のクリア時と最後に、結果カード画像を作る：削った形の絵、目標の点線、ランク、タイム、面の名前、ゲーム名
- スマホの共有機能（Web Share API）で画像付き投稿。使えない端末では画像の保存と、投稿文のコピー
- 記録（各面の最高ランク・最速タイム）は端末内に保存。保存できなくても遊べる

## 8. 決まっていること（ユーザー）
- 点線にぴったり合わせて削るのが遊びの芯
- 導入はばかばかしさで笑わせる
- 形はだんだん変わり、難しくなる
- 話は最後まで続く（案B）
- タイムと形で点数、ランクを共有
- 作り方は A（サーバーなし、結果カード共有）
- 最終面の顔は輪郭が顔に見える回転体
- 鉛筆は面ごとに新しい1本
- 止まるのは折れたときだけ。ランクで先へ進むのを止めない

## 9. 作り手にまかせること
- スマホのブラウザ向けで、1つの HTML ページにまとめるかどうか、ファイル構成
- 見た目の雰囲気、絵、音（効果音は作るか無料素材）
- 各面の目標形の具体的な輪郭、話の文章
- 採点の式・ランクの境目・折れの判定の強さ（遊んで調整）
- 公開の方法
